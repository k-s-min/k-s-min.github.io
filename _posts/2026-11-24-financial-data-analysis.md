## 프로젝트 개요

Python을 활용하여 미국 S&P 500 ETF인 SPY의
금융 데이터를 분석하고, 통계적 지표를 기반으로
투자 성과 평가 및 퀀트 투자 전략 설계를 학습하는
개인 프로젝트입니다.

## 문제 정의

단순한 수익률만으로는 금융 자산의 위험과
투자 성과를 종합적으로 평가하기 어렵습니다.

이에 과거 주가 데이터를 활용하여 수익률과 변동성을
분석하고, 정량적인 매매 신호를 생성하는 방법을
연구하고자 하였습니다.

## 프로젝트 역할

개인 학습 프로젝트로 다음과 같은 작업을 수행하였습니다.

- 금융 데이터 처리
- 일별 수익률 계산
- 수익률 기술통계량 분석
- 위험 대비 투자 성과 평가 방법 학습
- 모멘텀 기반 매매 신호 설계

## 활용 기술

- Python
- Pandas
- NumPy
- Probability & Statistics

## 데이터 분석 결과

SPY의 가격 데이터 4,023개를 활용하여
일별 수익률 데이터 4,022개를 분석하였습니다.

| 분석 지표 | 결과 |
|---|---:|
| 평균 일별 수익률 | 0.0579% |
| 일별 수익률 표준편차 | 1.0842% |
| 최대 일별 수익률 | 10.5019% |
| 최소 일별 수익률 | -10.9424% |

## 주요 구현 코드

### 일별 수익률 계산

```python
spy["Return"] = spy["Close"].pct_change()
spy["Return"].describe()
```

### 모멘텀 전략 및 매매 신호 생성

```python
spy["Momentum"] = spy["Close"].pct_change(20)
spy["Signal"] = (spy["Momentum"] > 0).astype(int)
```

20거래일 동안의 가격 변화율을 계산하고,
모멘텀이 양수인 경우 투자 신호를 생성하는
기초적인 추세 추종 전략을 설계하였습니다.

## 프로젝트를 통해 학습한 내용

- 금융 시계열 데이터 처리 방법
- 수익률과 변동성의 통계적 의미

- 모멘텀 기반 퀀트 투자 전략의 원리

- 시장 수익률과 전략 수익률 비교
- 거래 비용을 고려한 성과 분석
- 다양한 퀀트 투자 전략 연구
- 포트폴리오 최적화
